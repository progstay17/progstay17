# Contributing

Thanks for taking an interest in Ghifarion.

## Principles

- Keep documentation clear, useful, and accurate.
- Prefer practical examples over vague claims.
- Do not publish secrets, API keys, private user data, or credentials.
- Do not add fabricated metrics, testimonials, or project capabilities.
- Keep visual and written assets consistent with the brand tokens in `assets/brand-tokens.json`.

## Proposing a change

1. Explain the problem or improvement the change addresses.
2. Keep changes focused and easy to review.
3. Verify links and local asset paths before submitting.
4. Describe what was checked and call out anything that remains unverified.

## Scope

This repository contains Ghifarion brand/profile presentation assets and documentation. Application source code belongs in its respective project repository.
