PROJECT / STORAGE INFRASTRUCTURE

AIT Drive

A private cloud storage ecosystem connecting a web interface with files stored on a user's own computer or storage infrastructure.

Overview

AIT Drive separates account identity and permissions from local file storage. A web-facing Gateway manages users and access, while a local Agent handles file operations on the user's storage.

System components

  • Gateway & Web UI — authentication, accounts, quotas, permissions, administration, and browser interface.
  • Agent — local storage service and file-operation API.
  • Tools — CLI, MCP server, and AI skill for interacting with the Gateway.

Capabilities

  • Multi-account support, quotas, and permissions
  • Folder uploads and ZIP downloads
  • Search, trash, and restore
  • Expiring share links
  • Personal access token authentication

Architecture & security boundary

The Gateway handles identity and permissions. The Agent manages local files and is not intended to be directly exposed to the internet.
