MCAP2MP4

A Windows desktop and command-line application for converting MCAP camera recordings into MP4 video.

Overview

MCAP2MP4 provides a desktop and CLI workflow for converting supported MCAP camera recordings into MP4 video files, with batch processing and supporting inspection tools.

Capabilities

  • Batch conversion of recording files
  • Metadata inspection and report generation
  • Recording session management
  • Playback of one or two cameras
  • Configurable output and conversion options

Conversion approach

The main conversion workflow uses remuxing without re-encoding for supported formats. Compatibility depends on the source recording format and available streams.
