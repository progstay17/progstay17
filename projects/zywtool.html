ZYWtool

A Windows desktop toolkit for inspecting and managing MCAP recording sessions.

Overview

ZYWtool supports inspection and management of MCAP recording-session collections through a Windows desktop application.

Capabilities

  • Recursive session-folder search
  • Metadata and parsing audits
  • Recording health checks
  • Folder organization with undo
  • Timeline preview
  • Excel and Hand Check reports

PYTHON 3.12 · DESKTOP GUI · MEDIAPIPE · EXCEL · PYTEST
