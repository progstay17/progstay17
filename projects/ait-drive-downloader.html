AIT Drive Downloader

A web application for collecting files from multiple Google Drive links and packaging them into a single ZIP archive.

Capabilities

  • Process multiple public Google Drive file links
  • Export Google Docs, Sheets, and Slides
  • Stream ZIP archive creation
  • Handle duplicate filenames
  • Log files that could not be processed
