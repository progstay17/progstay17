MCAP to MP4 Drive Converter

A Google Colab notebook workflow for converting MCAP recordings stored in Google Drive into MP4 files.

Workflow

  • Mount Google Drive in the Colab environment
  • Process recording files one by one
  • Copy converted outputs back to Drive
  • Clean temporary files after processing

The project README documents support for selected recording formats, including certain H.265 recordings. Compatibility depends on the source data and notebook configuration.
